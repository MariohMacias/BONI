SECCIÓN 2 — CAPACIDADES ACTIVAS ✅

Chat con IA — Interfaz Holográfica (boni_ui.py)

Qué hace: Ventana circular translúcida 500×500px estilo JARVIS-IA, con orbe 3D pulsante, anillos concéntricos con marcas de tick, 22 partículas orbitales, scanlines, viñeta, y texto de respuesta. Se conecta directamente a Ollama en localhost:11434 para chat streaming.

Cómo usarla:

  1. Abre PowerShell y ejecuta: python "C:\Users\nosoy\OneDrive\Desktop\boni\boni_ui.py"
  2. La ventana aparece en la esquina superior derecha de la pantalla
  3. Presiona cualquier tecla alfanumérica → aparece el campo de texto oculto
  4. Escribe tu mensaje y presiona Enter → el orbe se ilumina y BONI responde
  5. Presiona Escape para ocultar el campo de texto
Ejemplo: Presiona 'H' → aparece input → escribe "¿Capital de Francia?" → orbe pulsa → responde "París"

Limitaciones: El historial no persiste al cerrar. Sin scroll de historial. Máximo 3 líneas de respuesta visibles.

Chat con IA — Web UI (boni_webui.py)

Qué hace: Servidor Flask en puerto 3001 con interfaz web moderna, sidebar con historial persistente en disco, Markdown renderizado, streaming SSE, selector de modelo.

Cómo usarla: python "C:\Users\nosoy\OneDrive\Desktop\boni\boni_webui.py" → abrir http://localhost:3001

Limitaciones: Backend apunta a jarvis serve (WSL:8080) no a Ollama directo.

Chat con IA — Ollama Directo (via API)

Qué hace: boni_ui.py intenta primero localhost:11434/api/chat, si falla usa localhost:8080/v1/chat/completions como fallback.

SECCIÓN 5 — GUÍA DE USO DIARIO

Iniciar BONI

  1. Verificar Ollama: curl.exe http://localhost:11434/api/tags
  2. Iniciar interfaz holográfica: python boni_ui.py
  3. Alternativa web: python boni_webui.py → http://localhost:3001
  4. Auto-inicio: powershell -ExecutionPolicy Bypass -File BONI_INICIO.ps1

Hablarle por Voz

Actualmente solo texto. Tecla Insert es placeholder visual. Cuando el TTS esté listo: Insert → hablar → respuesta con voz clonada.

Pedirle que Ejecute Código

Usuario: "Ejecuta python -c 'print(\"hola\")'"
→ BONI usa tool_sistema.py → responde con stdout

Pedirle que Investigue

# Simple: preguntar directo
# Profundo: wsl jarvis agent run boni-research "tema"
# Skills: arxiv, summarize, weather

Pedirle que Recuerde

Usuario: "Recuerda que mi cumpleaños es 15 de marzo"
→ BONI guarda en ~/.boni/memoria.json
Usuario: "¿Cuándo es mi cumpleaños?"
→ BONI: "15 de marzo"

Cerrar BONI

Menú contextual → "Salir", o Ctrl+Q, o desde system tray.
